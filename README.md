## 🧠 Vault — Terminal Notes Vault
Vault is a lightweight and fast terminal-based note vault built in Go.
Think of it as your personal Notion/Obsidian — but inside the terminal.
Clean, keyboard-first, and distraction-free productivity.


## 🌟 What vault Does
1.Create and store Markdown notes in ~/.totion
2.Open, edit, and save notes quickly
3.View a list of all notes with timestamps
4.No GUI, no mouse — pure terminal workflow
5.Powered by:
Bubble Tea (TUI)
Bubbles Components
Lipgloss Styling
A perfect tool for developers, terminal junkies, and minimalists.

## 📦 Installation

```
git clone https://github.com/your-username/totion.git
cd tot ion
go mod tidy
go run .

```
# Build binary

```
make build     # builds binary
make run       # runs the app
make clean     # remove binary
```
